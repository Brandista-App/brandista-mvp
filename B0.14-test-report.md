## Reproduction

1. Ensure JDK 21 and Docker Desktop are available.
2. From repository root, run `docker compose ps --all`, then `docker compose logs --no-color --tail 150 backend mysql`.
3. Run `Invoke-WebRequest http://localhost:8080/actuator/health -TimeoutSec 15`.
4. If MySQL is healthy while actuator returns 503, inspect the redacted backend error for datasource auth. Check whether `.env` credentials match the account initialized in the existing `mysql_data` volume. Avoid `docker compose down -v` unless database deletion is intended.
5. For automated checks, set `JAVA_HOME` to JDK 21 and run `.\mvnw.cmd test`. If global `C:\.m2` is inaccessible, set `MAVEN_OPTS='-Duser.home=<repo>\.maven-home'` and ensure Maven Central access.

See `B0.14-backend-audit.md` for severity-ranked blockers and `B0.14-api-contract.md` for frontend request/response details.
